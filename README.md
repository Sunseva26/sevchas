# Telegram Wallet Pro — упрощённая сборка Netlify (v3)

Эта версия не требует Supabase и отдельной базы. Баланс игровой валюты «рублики» и прогресс тапалки хранятся в Netlify Blobs. Единственная переменная окружения — `TELEGRAM_BOT_TOKEN`.

> Это кошелёк игровой валюты «рублики», а не реальные деньги, криптовалюта или платёжная система. Netlify Blobs в этой простой версии не даёт транзакционной блокировки между параллельными запросами; не используй её для денег или ценных активов.

## Настройка с телефона или компьютера

### 1. Создай бота
1. Открой Telegram и найди `@BotFather`.
2. Отправь `/newbot` и следуй подсказкам.
3. Скопируй токен. Если токен ранее отправлялся в чат или публиковался, сначала отзови его через BotFather (`/revoke`) и используй новый.

### 2. Опубликуй сайт на Netlify
1. Скачай ZIP и распакуй его.
2. Для этой версии необходимо загрузить сайт **вместе с Netlify Functions и зависимостями**. Самый надёжный способ — открыть Netlify CLI в папке проекта и выполнить:

   ```bash
   npm install
   npx netlify login
   npx netlify init
   npx netlify deploy --build --prod
   ```

   В мастере `netlify init` выбери или создай сайт. GitHub не нужен. Простая загрузка одной папки `public` опубликует только фронтенд и не включит функции.

### 3. Добавь единственную переменную
1. В Netlify открой свой сайт → **Site configuration** → **Environment variables**.
2. Нажми **Add a variable**.
3. Key: `TELEGRAM_BOT_TOKEN`
4. Value: вставь токен от BotFather.
5. Сохрани и запусти новый deploy (`Deploys` → `Trigger deploy` → `Deploy site`, либо снова `npx netlify deploy --build --prod`).

### 4. Подключи бота автоматически
1. Открой в браузере адрес своего сайта и добавь в конец `/.netlify/functions/setup`.
   Пример: `https://имя-сайта.netlify.app/.netlify/functions/setup`
2. Если настройка прошла, увидишь JSON с `"ok": true` и username бота. Эта страница автоматически зарегистрирует webhook и команды бота.
3. Открой своего бота в Telegram и отправь `/start`.

Если в ответе ошибка, проверь, что переменная `TELEGRAM_BOT_TOKEN` сохранена и после этого был новый deploy. Повторно открывать URL настройки безопасно.

### 5. Кнопка Mini App (необязательно)
Для открытия кошелька через встроенную кнопку сообщения `/start` уже достаточно. Чтобы добавить постоянную кнопку меню:
1. В `@BotFather` выбери своего бота → **Bot Settings** → **Menu Button**.
2. Укажи URL сайта целиком, например `https://имя-сайта.netlify.app/`.

## Команды
- `/start` — приветствие и кнопка кошелька
- `/balance` — баланс
- `/daily` — получить 10 рубликов раз в сутки UTC
- `/progress` — уровень и достижения
- `/history` — последние операции
- `/send @username 25` — перевод рубликов

Получатель должен сначала запустить бота и иметь Telegram username. Тапай по большой монете в Mini App: каждый успешный тап начисляет 1 рублик. Для первой проверки запусти бота с двух Telegram-аккаунтов: первый получит рублики через `/daily`, затем можно проверить перевод.

## Важное
- Данные сохраняются в Netlify Blobs и не должны пропадать при новом деплое.
- Не публикуй токен и не вставляй его в `public/index.html` или исходники.
- Если бот не отвечает: открой URL `/.netlify/functions/setup` ещё раз, затем проверь `Site configuration → Environment variables` и журналы функций Netlify.
- Не используй эту демонстрационную реализацию для реальных финансов: хранилище упрощённое, без транзакционных гарантий при одновременных переводах.


## Магазин дизайнов карт

В приложении есть 8 оригинальных векторных SVG-дизайнов: Классика, Неоновый дракон, Космос, Лавовый стиль, Лес, Королевская, Неон ночи и Киберпанк. Пользователь покупает карту за рублики, покупка проверяется серверной функцией, списание и владение записываются в Netlify Blobs. После покупки можно выбрать активный дизайн. Дополнительные переменные окружения не нужны — используется существующий `TELEGRAM_BOT_TOKEN`.

API Mini App: `POST /.netlify/functions/api/buy-card` с `{"card_id":"cosmos"}` и `POST /.netlify/functions/api/equip-card` с `{"card_id":"cosmos"}`; запросы должны содержать проверяемый `x-telegram-init-data`.

## Обновление: тапалка и подарок партнёра

- Один тап начисляет **100 игровых рубликов**. Сервер ограничивает слишком частые запросы.
- В разделе «Подарок от партнёров» показывается прогресс до 5 000 000 рубликов.
- При достижении порога кнопка активируется. Нажатие списывает 5 000 000 рубликов один раз на аккаунт, записывает операцию в историю и открывает страницу партнёра: https://share.flocktory.com/exchange/login?ssid=6988&bid=16319
- На странице партнёра могут действовать отдельные условия, ограничения и доступность подарков. Приложение не гарантирует выдачу подарка самим партнёром.
- Переменная окружения остаётся одна: `TELEGRAM_BOT_TOKEN`.

После обновления опубликуйте полную сборку Netlify Functions и `public` через Netlify CLI. Убедитесь, что Netlify Blobs включён для сайта. Для уже существующих аккаунтов значение статуса обмена по умолчанию — `false`.
